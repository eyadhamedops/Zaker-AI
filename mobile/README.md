# Zaker AI Mobile

This folder contains the Flutter mobile app starter for the project.

## Setup

```bash
cd mobile
flutter pub get
flutter run
```

## Notes

- The app uses a mock backend by default.
- To connect to the real backend, make sure `http://127.0.0.1:8000` is running.
- For Android APK generation use:

```bash
flutter build apk
```
